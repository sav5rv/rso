### Exemplos de Prompts para me ajudar a te ajudar

Aqui estão alguns modelos de prompts que você pode usar para me fornecer informações e solicitar assistência durante seus projetos. Eles são organizados por tipo de tarefa.

#### 1\. Para Depurar (Corrigir Erros)

Se o seu código está com um erro e você precisa de ajuda para encontrar a causa.

**Modelo de Prompt:**

"Estou com um erro no meu programa e não consigo descobrir o motivo. A minha meta era \[descreva o que o código deveria fazer\], mas está acontecendo o seguinte \[descreva o comportamento ou erro que você está vendo\].

Aqui está o código relevante e a mensagem de erro:

**Arquivo:** `[nome_do_arquivo]` `[Cole o trecho do código]`

**Mensagem de erro no console:** `[Cole a mensagem de erro completa]`

O que pode estar causando isso?"

#### 2\. Para Criar Código do Zero

Se você tem uma ideia e precisa de ajuda para escrever o código.

**Modelo de Prompt:**

"Preciso de ajuda para criar um código em \[linguagem de programação\] para \[descreva a tarefa que o código deve realizar\].

**Detalhes e Requisitos:**

*   \[Liste os requisitos, por exemplo: 'O código deve ler um arquivo `.txt`...'\]
    
*   \[Outro requisito, por exemplo: '...e contar a frequência de cada palavra.'\]
    
*   \[Qualquer outra informação relevante, por exemplo: 'Ignore pontuação e letras maiúsculas/minúsculas.'\]"
    

#### 3\. Para Entender um Código Existente

Se você encontrou um trecho de código e quer entender como ele funciona.

**Modelo de Prompt:**

"Não entendi a lógica deste código em \[linguagem de programação\]. Poderia me explicar o que cada parte faz?

**Trecho de código:** `[Cole o trecho do código]`

Minha principal dúvida é sobre \[mencione a parte específica que você não entendeu, por exemplo: '...a função `map()`'\].

#### 4\. Para Otimizar ou Melhorar um Código

Se o seu código funciona, mas você quer torná-lo mais eficiente, limpo ou legível.

**Modelo de Prompt:**

"Este código funciona, mas parece que pode ser melhorado. Você pode me sugerir uma forma de otimizá-lo?

**Linguagem:** \[linguagem de programação\] **Objetivo:** \[descreva o que o código faz\] **Código:** `[Cole o código]`

Eu pensei em \[mencione suas ideias para a otimização, se tiver alguma\], mas não tenho certeza se é a melhor abordagem."

Ao usar esses modelos, você me fornece as informações de que preciso para te ajudar de forma mais eficiente. Fique à vontade para adaptá-los conforme a sua necessidade.
